Session 04는 필사본·고문서처럼 정형화되지 않은 한국학 사료를 Python 기반 OCR로 데이터화하는 방법을 다룬다고 소개되어 있었다. 나는 딥러닝을 공부하면서 OCR 파이프라인을 직접 구성해본 경험이 있어서, 이 주제를 그 경험에 비추어 스스로 구현해보았다.

비정형 사료 OCR이 어려운 이유

일반 문서 OCR과 달리 고문서·필사본 OCR은 다음 지점에서 난이도가 크게 올라간다.

  • 활자가 아닌 필사체라 글자 형태의 변이가 크다
  • 세로쓰기, 행간 불규칙, 훼손·얼룩 등 레이아웃이 표준적이지 않다
  • 한자·이두·고어가 섞여 있어 범용 OCR 모델의 어휘 사전과 맞지 않는다

일반적인 파이프라인 구성

워크숍 소개 자료의 문제의식과, 내가 실제로 구성해본 파이프라인을 종합하면 대략 다음 단계로 정리된다.

  1. 전처리: 이진화, 노이즈 제거, 기울기 보정 (OpenCV)
  2. 레이아웃 분석: 문단·행 단위 영역 검출 (예: CRAFT, DBNet 계열의 텍스트 검출 모델)
  3. 문자 인식: 검출된 영역을 CRNN, TrOCR류의 시퀀스 인식 모델에 통과
  4. 후처리: 언어모델 기반 교정, 이체자·이형자 정규화

참고할 만한 오픈소스 도구

  • Tesseract: 범용 OCR, 활자본에는 강하지만 필사체엔 한계가 뚜렷함
  • PaddleOCR: 텍스트 검출+인식 파이프라인이 통합되어 있어 커스텀 데이터로 파인튜닝하기 수월함
  • TrOCR (Transformer 기반): 손글씨 인식에 강점, 한국 고문서 특화 데이터로 파인튜닝 시 성능 향상 여지가 큼
💡 이 주제를 구현하며 스스로 정리한 지점: OCR 정확도 못지않게, 인식된 텍스트를 어떻게 구조화된 데이터(예: 인명·지명·연호 태깅)로 전환할지가 인문학적 활용의 관건이 된다는 것이었다. 단순 텍스트 추출에서 끝나면 "사료의 데이터화"라기보다 "사료의 텍스트화"에 머문다.

내가 실제로 구현해본 것

✏️ 이 부분에 본인의 실제 프로젝트 내용을 채워 넣으세요. 예시 구조:
  • 사용한 데이터(어떤 고문서/사료, 몇 장 정도)
  • 사용한 모델·프레임워크(PyTorch, HuggingFace TrOCR 등)와 파인튜닝 방식
  • 정량 평가 지표(CER/WER 등)와 결과
  • 한국학 자료 특유의 이체자·고어 처리를 위해 추가한 후처리 로직

간단한 전처리 예시 코드

import cv2

def preprocess(image_path):
    img = cv2.imread(image_path, cv2.IMREAD_GRAYSCALE)
    # 이진화
    _, binarized = cv2.threshold(img, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)
    # 노이즈 제거
    denoised = cv2.fastNlMeansDenoising(binarized, h=15)
    return denoised
✏️ 위 코드는 자리표시자입니다. 실제로 사용한 전처리·인식·후처리 코드로 교체하세요.

Session 03과의 연결점

OCR로 데이터화된 사료 텍스트는 그 자체로 끝나지 않는다. Session 03 주제로 구현해본 현대시 텍스트 분석과 마찬가지로, 데이터화된 사료 역시 형태소 분석·임베딩·시각화 단계로 이어질 수 있다. 결국 두 세션 주제는 "비정형 텍스트 → 구조화된 데이터 → 정량적 해석"이라는 같은 흐름의 앞뒤 단계를 각각 다룬 셈이다.
