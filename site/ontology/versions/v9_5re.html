독립운동-근대학교 온톨로지 v9.5re — Claim 기반 근거모델

v1~v8의 Event 중심 스키마에서 한 걸음 더 나아가, 사실 하나하나를 Claim(주장) 단위로 분리하고 각 Claim에 출처(Source)·근거(Evidence)·검증상태·리뷰플래그·변경이력까지 개별적으로 붙인 모델입니다. Claim 39건 중 core 34건(신뢰도 확보, 실선)과 hold 5건 (관계·해석 추가검증 필요, 점선)을 구분해 표시합니다. v9_5.ttl 원본을 브라우저에서 직접 파싱해 그렸습니다 (하드코딩 없음).
v9.5re 추가 사항: 데이터(core/hold)는 v9.5와 완전히 동일합니다. 다만 v9.5 검토 과정에서 date_status="not_applicable" 판정 6건("참여 Claim") 중 2건 (CLM-024, CLM-027-04)이 "합류하였다"/"이끌었다" 같은 동작 동사를 쓰고 있어, 다른 4건 (지위·성격 서술)과 달리 not_directly_verified가 더 적합할 수 있다는 재검토 의견이 있었습니다. 이 판단은 아직 확정되지 않았으므로 데이터의 core/hold 상태는 바꾸지 않고, 지도·관계망·상세패널에만 "🔍 의미론 재검토 권고" 표시를 추가했습니다 — 데이터 상태(core/hold/excluded)와 시각화상의 검토 의견(review)을 섞지 않기 위함입니다.
